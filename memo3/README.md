This folder contains all the code for Memo3

cpp_impl/ contains the empirical-data-generating algorithm, implemented in c++ (it has its own README file)

memo3_algorithm.py is the updated (slightly) implementation in python

memo3_algorithm_test.py was used for generating data_facility.csv, which was unused, and for running text cases

memo3.py is the updated marimo file

raw_pseudocode.txt is used to contain the pseudocode in the marimo file before it is formatted

references.txt is the references file, updated

data/ contains data files for the marimo file:
- data_facility.csv contains data on various numbers of wings, supplies, drone capacities, e.c.t.
- data_facility_small.csv contains data on the main facility with 2-4 wings, 50 supplies, e.c.t.
- flame_facility_small.csv contains the data for the flame graph visualisation

media/ contains media used in the marimo file
